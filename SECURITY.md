# Security

## Reporting a vulnerability

Report it privately through GitHub Security Advisories: on this repository's **Security** tab,
choose **Report a vulnerability**
([direct link](https://github.com/Deveshu04/Butterfly-Speak/security/advisories/new)). Do not
open a public issue.

Include the version (shown on the app's **Help & about** page), what an attacker can do, and
the steps to reproduce it. You will get a reply within 7 days.

## Scope

In scope:

- the desktop app (`src/`, `src-tauri/`)
- the relay behind Cloud mode (`relay/`)
- the database schema (`supabase/`)

Out of scope: Sarvam AI, Supabase and Cloudflare themselves. Report problems in their services to
them.
